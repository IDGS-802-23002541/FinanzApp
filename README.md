# FinanzApp

Sistema integral para la gestión de finanzas personales.

FinanzApp está compuesto por tres aplicaciones que trabajan como un mismo proyecto:

- **Web:** aplicación web desarrollada con React, Vite y Material UI.
- **Móvil:** aplicación nativa Android desarrollada con Kotlin y Jetpack Compose.
- **Backend:** API REST desarrollada con Python y Flask.
